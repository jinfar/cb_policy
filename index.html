Chess Battles uploader

The upload tool of the Chess Battles YouTube channel

Chess Battles is a YouTube channel with online blitz chess games between two streamers: both players' cameras, one board, an engine evaluation and English subtitles. Every video credits both streamers and links to their channels.

Chess Battles uploader is a private command-line tool that only the channel owner uses, on the owner's own computer. It uploads the channel's own videos, their titles, descriptions, tags, subtitle tracks and thumbnails to the Chess Battles channel through the YouTube API Services. It has no website, no user accounts and no other users, and it is not offered to anyone else.

Privacy policy

Effective October 12, 2026

This policy describes how Chess Battles uploader (“the tool”) uses data. The tool uses YouTube API Services. By using YouTube through the tool you are bound by the YouTube Terms of Service, and Google's handling of your data is described in the Google Privacy Policy.

Who uses the tool

Only the owner of the Chess Battles channel. The tool signs in with Google OAuth as the channel owner and acts only on that channel. No one else can sign in to it, and it collects no data from viewers or from any other user.

What data the tool accesses

  • The channel owner's YouTube account, through the OAuth permissions youtube.upload and youtube.force-ssl: to upload the channel's videos, set their titles, descriptions, tags, privacy status and thumbnails, and add, list or replace their subtitle tracks.

What data the tool stores

  • The OAuth access and refresh token of the channel owner's sign-in, in a local file on the owner's computer.
  • For each uploaded video: its YouTube video id, link, upload time, privacy status, and which subtitle tracks and thumbnail were sent, in local files on the owner's computer.

Nothing is stored on any server run by the tool (there is none). The tool uses no cookies, no analytics and no tracking.

How the data is used and shared

The data is used only to upload and manage the Chess Battles channel's own videos and to credit the streamers in them. It is not sold, not shared with anyone, not used for advertising, and not combined with data from other sources. The only party that receives data from the tool is Google, through the YouTube API Services.

Keeping and deleting data

  • Stored data is kept only as long as it is needed to manage the uploaded videos. Data about a video is deleted when the video is deleted from the channel.
  • Data obtained from the YouTube API Services is refreshed or deleted as the YouTube API Services Developer Policies require.
  • The channel owner can revoke the tool's access to the account at any time on the Google security settings page; the stored sign-in token then stops working, and the local file that holds it can be deleted.
  • A streamer who wants their channel links removed from the tool's data, or a video taken down, can ask through the contact below; the request is handled promptly.
